# Memory index

Generated by `.agents/tools/memory-index`; do not edit by hand.
Regenerate it after every memory you create, update, rename or delete, in the same change.
One line per shared memory: name, description, tags.
Open a memory's file only when its description is relevant to the task.
Local `user` memories are not listed here; read every file in `.agents/memories/user/`.
