# Shared Claude Code and Codex settings

This repository keeps portable defaults for Claude Code and Codex in one place.
The installer renders user-level configuration files because both tools require absolute paths for hooks and may record machine-specific state.

## Install on a new machine

Clone this repository somewhere stable, then run:

```sh
./scripts/install-agent-settings
```

The script writes `~/.codex/config.toml` and `~/.claude/settings.json`.
It detects the repository location automatically and inserts that path into hook and status-line commands.
If it finds an existing config that was not generated by this script, it moves it to a timestamped `.backup` file first.

Run a no-change preview with:

```sh
./scripts/install-agent-settings --dry-run
```

## Per-machine Codex project trust

Do not commit trusted-project paths because they depend on the machine.
To add them, copy and edit the example:

```sh
cp config/codex/config.local.toml.example ~/.codex/config.local.toml
```

Then rerun the installer.
The local file is appended to Codex's generated config and remains outside this repository.

## Updating shared settings

Edit the files under `config/`, then rerun the installer on each machine.
Keep shared hooks and scripts in this repository.
Do not add Codex's `[hooks.state]` or absolute `[projects]` paths to the templates because Codex creates those as local state.
